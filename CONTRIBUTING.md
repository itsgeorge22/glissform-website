# Contributing

Glissform development is paused. Small website fixes may be considered, but ongoing maintenance and responses are not guaranteed. Discuss substantial changes in an issue before investing time in them.

## Report a website issue

Describe the problem, the affected URL, your browser and what you expected. Include a screenshot only when it helps; remove personal information first. Never include credentials, cookies, private logs or device serial numbers.

Native app issues belong in [itsgeorge22/glissform](https://github.com/itsgeorge22/glissform/issues).

## Propose a fix

1. Keep the change focused and follow [AGENTS.md](AGENTS.md).
2. Preserve keyboard access, reduced-motion alternatives, privacy choices and existing downloads.
3. Run `npm run build` and `npm run test:deploy`; inspect affected visual states when relevant.
4. Explain the change and the checks performed in your pull request.

Do not commit generated files, credentials, local machine paths or private account information. Do not alter signed update-feed bytes or release assets as part of a website fix. Publication and production account changes are handled by the maintainer.

No project-wide license is granted by this repository. Preserve all third-party notices.
