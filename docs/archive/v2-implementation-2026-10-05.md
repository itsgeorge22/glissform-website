## Development

Requires Node 22.12 or later. Node 24 is used locally.

```sh
npm ci
npm run dev       # http://127.0.0.1:5180/
npm run build     # typecheck and generate the static hero in dist/
npm run preview   # http://127.0.0.1:4180/
npm run test:hardware
npm run test:hero-animation
npm run test:hero-stars
```

Astro can run its local servers in the background. `npx astro dev stop` and `npx astro preview stop` stop this checkout's servers. Generated artwork, dependencies, caches and build output are ignored by Git. Earlier Vite sources remain as reference and can run with `npm run dev:legacy` on port 5181; they are not routes in the new Astro build. See the [previous website reference](legacy-website.md) for historical implementation and deployment details. Its earlier measurements do not describe this candidate.

- The page hides its scrollbar using the standard CSS rule and browser-specific fallbacks. Native wheel, trackpad, touch and keyboard scrolling continue to drive the existing animation.
- Direct Three.js WebGL2 renders the original Glissform silver enclosure, bezel and lid proportions. The original procedural keyboard, lettering, recessed Touch ID and plain lower screen edge are restored. Apple’s M5 Pro supplies the retained hinge and scoop shape. The final resting pose faces forward without sideways rotation or roll and stays **28° open** on the surface, preserving a strip of the live screen. The sticky section releases into normal scrolling at the reveal endpoint, with the Mac remaining in its resting pose. The stage and page use pure white, with the original silver material and studio lighting and no added screen emitter or surrounding glow. The opening screen hero remains dark.
- The ending places “Satisfying even when / it’s time to close” in two equal black lines above the centered Mac. Its distinct two-line subtitle reads “Customize your MacBook lid animation with Seamless Close. / Choose the starting angle and blur strength in Glissform for macOS.” It explains customization and names the feature, product and platform without repeating the hero's visual-effect description. Both scenes share fixed Manrope typography: 600 weight at 64/72px with −0.04em tracking for headings, and 400 weight at 18/28px with normal tracking for subtitles. The ending retains its dark heading and gray subtitle colors. Both reveal character by character through a reversible fade and upward unfold; accessible labels keep each phrase intact. The subtitle retains its entrance start but settles earlier, using a 0.24 span on the choreography timeline. The reveal preserves its original motion distance but trims the unused final 6% of the scroll travel. The reveal uses 94% of the original travel (`max(340svh, 2300px) - 100svh`), so the Mac reaches its resting pose at the original motion endpoint. The model follows native scrolling with its original 65ms smoothing. There is no added transition zone or section-position transform.
- The ending copy keeps its 32px downward layout offset and internal spacing. At the resting pose, the enlarged Mac is centered with exactly 128px between the bottom of the copy block and the top of its projected silhouette. It targets a width up to 1280px with 64px side margins and scales down when needed to leave 48px below the model.
