# Stay updated visual

`download.svg` is the unmodified artwork exported from the owner-provided Stay updated Figma reference (original design reference), retrieved 2026-10-12. It retains the original 38.5542 × 38.5542 geometry and blue fill as the source reference.

The centered card, text, icon tile and Update button are rendered with HTML and SCSS, following the 400 × 204.819 card inside the 696 × 696 design. The illustration scales uniformly with the desktop feature panel and shares its existing transition compensation.

For the owner-requested download-to-loader morph, `stayUpdatedIcon.ts` preserves both original filled paths. `StayUpdatedVisual.tsx` renders these as inline SVG with a dynamic color, pulls the arrow up before a vertically compressed dive into the shelf, clips its absorption, and replaces the shelf with a matching centerline during the transition. Five cubic segments curl that centerline into the same short 140-degree lower arc with a counterclockwise recoil followed by a clockwise launch; the stroke grows from 3.21285 to 4.3 design units with a small spring settle. Neither endpoint stretches out into a full circle. On completion, a continuous track reverses the original arc’s path traversal without changing its shape, matching the loader’s clockwise spin, then extends through a clockwise tangent curve into a checkmark drawn in code. A moving stroke window transfers the line along that track, entering the nearest upper-right tip, drawing down the long arm to the corner, then finishing up the short left arm; the trailing end follows into place. The check is counter-rotated into the stopped spinner’s frame so its final orientation stays upright and the arc does not snap. It retains the loader's stroke weight and rounded caps and joins. The original paths return unchanged at reset and in the reduced-motion fallback. The celebration's colored confetti is generated in code with no additional external artwork.
